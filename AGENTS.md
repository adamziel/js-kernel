## JavaScript kernel

The JavaScript kernel is a kernel that is used to simulate a basic POSIX-like environment in the browser.

When writing code:

* Never produce markdown files explaining the change, unless explicitly asked for.
* Prefer more conscise solution that reuses existing parts of the system. Slightly refactor them when needed.
* Do not produce scripts to run or test your change such as `run.sh` or `test.js`, unless explicitly asked for.
